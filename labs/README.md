# قيادة تبني الذكاء الاصطناعي والتغيير · المختبرات

أربعة مختبرات لمقرر أكاديمية سدايا **LDS-EXE-204**، بالترتيب الذي يذكره المقرر. المختبرات صفحات إرشادية بالعربية تُعمل في جدول بيانات وفي مساعد مستضاف: الهدف، والملفات، والخطوات بدقائقها، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للمدرّب. لا كود يكتبه المشارك.

كل المختبرات في جهة واحدة: **إدارة التعليم في مدينة الجُمان، المكتب الرئيس**، جهة افتراضية لمدينة افتراضية فيها 345 موظفًا في ستة فرق، ومساعدها المؤسسي المعتمد «مِعوان». كل الأسماء والأرقام مخترعة، وكل الملفات مجمّعة أو منقّاة ومصنفة «عام»: لا اسم موظف ولا طالب في أي ملف.

## ما يحتاجه المشارك

- جدول بيانات: LibreOffice Calc أو Microsoft Excel. وللمختبر 2.1 أداة لوحات مثل Apache Superset أو Metabase إن كانت متاحة، وجدول البيانات يكفي.
- مساعد مستضاف للمختبر 1.2: نموذج مستضاف مفتوح الأوزان في خدمة مجانية، أو المساعد المؤسسي المعتمد في جهة المشارك. لا يُدخل فيه إلا ملفات المقرر.
- أداة استبانات (LimeSurvey أو Microsoft Forms) للمهمة الإضافية في 2.1 فقط.

## للمدرّب: المفتاح والأدوات

- `solutions/answer_key.md`: كل ما زُرع في الملفات، وأين، وأي مختبر يكشفه.
- `solutions/key.json`: الأرقام المرجعية كلها، يكتبها المولّد.
- `solutions/check_all.mjs`: يتحقق أن المولّد يكتب البايتات نفسها، ويعيد حساب كل رقم مرجعي من ملفات CSV بطريقة جدول البيانات، ويتحقق من الملفات الثابتة. يطبع PASS أو كل اختلاف.

الأدوات بلغة JavaScript ولا تحتاج غير Node 22 أو أحدث، وتُشغَّل من جذر المستودع:

```
node labs/_tools/prepare_files.mjs
node labs/solutions/check_all.mjs
```

الأول يعيد كتابة ملفات CSV المولّدة و`solutions/key.json`. مع `--check` لا يكتب شيئًا ويقارن فقط.

البنود في `files/ap_am_extract.csv` رموزها رسمية من إطار المعايير المهنية في البيانات والذكاء الاصطناعي (سدايا، النسخة الثانية، سبتمبر 2026، القسم 5)، وصياغتها المختصرة من المقرر، لا نص الإطار.
