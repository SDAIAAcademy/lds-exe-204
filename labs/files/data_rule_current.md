# التعليمات الحالية لاستخدام الذكاء الاصطناعي

إدارة التعليم في مدينة الجُمان (جهة افتراضية). التصنيف: عام. صدرت مع إتاحة «مِرقاة»، ولم تُحدَّث منذ ذلك.

> يُمنع إدخال أي بيانات مالية أو إدارية أو تخص الطلاب أو الموظفين في أدوات الذكاء الاصطناعي. ويُسمح بالاستخدام للأغراض العامة فقط. وعلى الجميع الالتزام بالأنظمة.

لم يُرفق بالتعليمات مثال، ولم تذكر من يُسأل عند الشك، ولم تذكر الأدوات العامة غير المعتمدة.
